# Chapitre 1 : Le Jeu du Dé

Ceci est le premier exemple du cours, le jeu "21-avec-un-dé". C'est un problème de décision séquentielle simple où à chaque tour, nous devons choisir entre deux actions : lancer le dé ou s'arrêter.

## Application pratique

Pour illustrer ce concept, j'ai développé une petite application web.

[➡️ Lancer l'application du Jeu du Dé](http://127.0.0.1:5000)

*(N'oubliez pas de lancer le serveur `app.py` dans un terminal pour que le lien fonctionne !)*
